1. MODNet (assets/poster/modnet_q.bin), a network for portrait matting
   Zhanghan Ke, Jiayu Sun, Kaican Li, Qiong Yan, Rynson W.H. Lau: "MODNet: Real-Time Trimap-Free Portrait Matting via Objective Decomposition", AAAI 2022.
   Apache Licence 2.0.
   https://github.com/ZHKKKe/MODNet  (licence: https://www.apache.org/licenses/LICENSE-2.0)

   The file in this app is a CONVERTED and COMPRESSED copy, not the original weights:
   - source: the ONNX conversion published as Xenova/modnet on Hugging Face (onnx/model.onnx,
     SHA-256 07c308cf0fc7e6e8b2065a12ed7fc07e1de8febb7dc7839d7b7f15dd66584df9);
   - changes made by Auralys: the graph was rewritten into Auralys's own small program format (the same arithmetic: convolutions,
     batch / instance normalisation, squeeze-excitation, bilinear resizing); the larger weight tensors were compressed with per-channel
     palettes (k-means, 3 to 6 bits per weight) and the biases of the compressed layers were corrected for the compression; the small
     layers are kept as 16-bit floats. The result is close to, but not identical with, the original network's output.
   - resulting file SHA-256 dc1f8065d742c23ee5bce7cdda8ddee4ea767058902bc80725c4bddd92a84af9.

The network runs on the phone itself, in the app's own code; photos are processed on the device and are never sent anywhere.
